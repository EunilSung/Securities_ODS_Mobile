ODS, 고객과 함께 보는 화면

ODS 는 직원 혼자 보는 앱이 아닙니다. 상담 테이블 위에서 태블릿을 고객 쪽으로 돌려 시세를 보여 주고, 비밀번호와 서명은 고객이 직접 넣습니다. 이 문서는 지금 앱의 모습을 정리하고, 그 위에서 바꾸면 좋을 것을 제안합니다. 시안의 고객·시세·금액은 모두 예시 값입니다.

  • 위험등급·투자성향 색 — 등락색을 빌려 쓰지 않는 전용 단계색
  • 고객 화면 띠 — 고객이 보는 단계(비밀번호·서명·보여 주기)는 위에 청록 띠와 큰 글자
  • 테마 구조 — getter 마다 다크 여부를 묻는 AppColors → MTS 처럼 OdsTheme 한 벌

제안: 직원 화면은 촘촘하게, 고객이 보는 순간은 크고 단순하게 제안

목록·상세·상담 칸처럼 직원이 보는 화면은 지금처럼 정보를 많이 담고, 비밀번호·서명·시세 보여 주기처럼 고객이 보는 순간은 글자를 키우고 직원용 정보를 감춘 뒤 위에 ‘고객 화면’ 띠를 둡니다. 색은 등락에만 빨강·파랑을 쓰고, 선택 상태는 무채색, 위험등급은 전용 단계색으로 떼어 놓습니다.

등락색은 등락에만 선택은 무채색 위험등급 전용 색 고객 화면 띠 개인정보 가리기 기본 태블릿 3칸 상담 칸

지금 세그먼트·선택 줄·주간 달력의 고른 날이 남색 PrimaryMain이고, 바로 옆 하락 숫자가 #1D64DA입니다. MTS 처럼 선택 상태는 진한 무채색(selected)으로 바꾸고, 남색은 브랜드 자리(주 버튼·로그인·탭 아이콘)에만 남깁니다.

위험등급·투자성향은 전용 단계색 제안

지금 상품 1·2등급은 상승 빨강, 5·6등급은 하락 파랑을 씁니다. 고객 앞에서 ‘빨강 = 오른다’로 읽힐 수 있어, 등락과 겹치지 않는 자홍~청록 여섯 단계를 따로 둡니다. 투자성향도 같은 단계색에 맞춥니다(안정형 청록 … 공격투자형 자홍).

고객이 보는 순간은 띠로 알리기 제안

계좌 비밀번호·서명·시세 보여 주기 화면 맨 위에 청록 ‘고객 화면’ 띠를 둡니다. 직원은 태블릿을 건넬 때를, 고객은 자기 차례임을 알 수 있습니다. 이 화면들은 제목 22sp 이상, 키패드 키 64dp 이상으로 키우고 직원용 정보(다른 고객·상담 칸)는 그리지 않습니다.

적용 보여 주기는 이미 전체 화면 · 제안 띠·큰 글자 스타일

개인정보는 기본으로 가리기 적용

전화번호 가운데, 생년월일은 연도만, 주소는 시·구까지, 계좌번호는 가운데를 가립니다. 상세 제목줄의 눈 버튼으로 앱 전체 설정을 바로 바꾸고, 자동 상담 기록에는 가린 계좌번호만 남깁니다.

경고는 주황, 등락은 빨강·파랑만 적용

적합성 부적합, 재진단 필요, 성향 미진단, 숙려기간, 입력 오류는 모두 Caution(주황)입니다. 빨강을 쓰면 ‘상승’으로 읽힙니다.

숫자는 고정폭으로 적용

현재가·호가·금액·시각은 tnum 스타일로 그려 값이 바뀌어도 자리가 흔들리지 않습니다. 글꼴은 아직 기기 기본이라 Android·iOS 모양이 다릅니다 — Pretendard 를 넣자는 것이 제안입니다.

현장에서 쓰는 크기 적용

서서 한 손으로 드는 경우가 많아 누르는 곳은 40dp 이상(목록 줄·탭·버튼), 키패드 68dp, 주 버튼 52dp 높이입니다. 단계 화면의 이전·다음은 늘 화면 아래에 고정합니다.

시연 데이터임을 보이기 제안

지금은 로그인 안내·앱 정보·보여 주기 아래에만 ‘시연용’이라고 씁니다. 로컬 모드에서는 화면 제목 옆에 작은 ‘시연’ 배지를 두어 고객이 실제 계좌로 오해하지 않게 합니다.

Compose 구현

이렇게 바꾸자는 것

1. 색·글자를 OdsTheme 한 벌로 제안

지금 AppColors 는 프로퍼티마다 isSystemInDarkTheme() 를 부릅니다. MTS 처럼 불변 객체 두 벌을 CompositionLocal 로 내려 주면 화면은 OdsTheme.colors.selected 로 읽고, 앱 안 테마 고르기도 dark 한 곳만 바꾸면 됩니다.

@Immutable
data class OdsColors(
    val bg: Color, val gray50: Color, val gray100: Color,
    val text: Color, val textSub: Color, val textDisabled: Color,
    val brand: Color, val brandSoft: Color,
    val selected: Color, val onSelected: Color,
    val rise: Color, val fall: Color, val caution: Color,
    val riskGrades: List<Color>,   // 1~6등급
    val customer: Color, val customerSoft: Color,
) {
    fun of(grade: ProductRiskGrade) = riskGrades[grade.level - 1]
    fun of(profile: RiskProfile) = of(profile.maxProductRisk)
}

@Composable
fun OdsTheme(dark: Boolean = isSystemInDarkTheme(), content: @Composable () -> Unit) {
    CompositionLocalProvider(
        LocalOdsColors provides if (dark) DarkOdsColors else LightOdsColors,
    ) { MaterialTheme(colorScheme = …, content = content) }
}

2. 고객 화면은 틀 하나로 제안

계좌 비밀번호·서명 단계와 보여 주기가 CustomerFacing 으로 감싸면 띠·큰 제목·키패드 크기가 한 번에 바뀝니다. 넓은 태블릿에서는 이 틀이 떠 있는 동안 상담 칸을 그리지 않습니다.

@Composable
fun CustomerFacing(
    title: String,
    content: @Composable ColumnScope.() -> Unit,
) {
    CompositionLocalProvider(LocalCustomerFacing provides true) {
        Column {
            CustomerBanner()             // 청록 띠
            Text(title, style = OdsTheme.type.customerTitle)
            content()
        }
    }
}

적용 순서

다섯 단계로 나눠 넣기

1

토큰 정리 제안

OdsTheme 도입, 선택 상태를 selected 로. 화면 수정은 세그먼트·주간 달력·체크박스·키패드 점 네 곳.

2

위험등급 단계색 제안

riskGrade1~6 과 RiskGradeBadge. 상품 목록·상세·적합성 카드·고객 성향 배지를 바꾸고, 단계색이 빨강·파랑 계열로 돌아가지 않게 테스트로 막음.

3

고객 화면 틀 제안

CustomerFacing 으로 계좌 비밀번호·서명 단계·보여 주기를 감싸고, 넓은 태블릿에서는 그동안 상담 칸을 그리지 않음.

4

글꼴 · 시연 배지 제안

Pretendard(MTS 와 같은 네 굵기) 번들, 로컬 모드 ‘시연’ 배지.

5

다음 남음

상담 칸 빠른 업무 버튼, 가입·개설 완료 확인서, 신분증 촬영 안내선, 앱 안 테마 고르기, 회사 CI 반영.

결정

정한 것과 정할 것

정함 등락색국내 관례 — 상승 빨강, 하락 파랑. 색만으로 알리지 않게 ▲▼ 와 부호를 함께.
정함 기본 테마기기 설정을 따름. 라이트·다크 같은 토큰 이름.
정함 개인정보가리기 기본 켬. 신분증 사진·주민번호 뒷자리·계좌 비밀번호·서명 그림은 저장하지 않음.
정함 태블릿1000dp 이상 3칸, 오른쪽 끝은 상담 칸.
정할 것 방향C(상담 테이블)로 갈지.
정할 것 브랜드 색지금 남색을 유지할지, 회사 CI 색으로 바꿀지. 어느 쪽이든 선택 표시는 무채색으로 떼어 냄.
정할 것 고객 화면 테마기기가 다크여도 고객 화면은 늘 라이트로 보일지(고객 쪽 가독성).
정할 것 글꼴Pretendard 를 MTS 와 같이 쓸지.

시안의 고객·계좌·일정·시세 숫자는 모두 예시 값이며 실제 고객 정보나 시세가 아닙니다.
